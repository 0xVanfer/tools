# ETH Dev Tools

A collection of browser-based utilities for Ethereum developers: decode calldata, extract function
signatures from source code, batch-read contract state, inspect addresses, and browse chains and
protocols.

Everything runs client-side — there is no backend, and no payload or key ever leaves your browser.

Live site: <https://0xvanfer.github.io/tools/>

---

## Tools

| Tool | Route | What it does |
| --- | --- | --- |
| **Payload Parser** | `#/payload` | Decode transaction calldata. Detects Safe `execTransaction` / `multiSend`, Multicall / Multicall3 `aggregate` / `aggregate3`, and recursively decodes nested `bytes`. Resolves unknown selectors via a local signature database and the 4byte API. Renders the addresses it finds with their token symbols and contract names. |
| **Signature Extractor** | `#/signature` | Extract function and custom-error signatures (with selectors) from a GitHub / GitLab / self-hosted GitLab repository, from a verified contract on a block explorer, or from pasted Solidity source. Uses a lightweight comment-aware Solidity parser that flattens structs and enums into ABI types and resolves proxy implementations. Exports JSON / CSV / Markdown, or generates an ABI. |
| **Contract Reader** | `#/contract-reader` | Batch contract reads through Multicall3 over any JSON-RPC endpoint. Load the verified ABI (proxy implementations included) or type a signature manually, queue calls, then optionally compare results against a production RPC when reading from a Tenderly Virtual Environment or a fork. |
| **Address Checksum** | `#/checksum` | Extract every Ethereum address from arbitrary text and convert it to EIP-55 checksummed and lowercase form. Flags invalid checksums and duplicate matches. |
| **Vanity Generator** | `#/vanity` | Generate addresses matching a hex prefix/suffix using Web Workers, with configurable target count and timeout. Private keys are generated locally. |
| **Block Explorers** | `#/explorers` | Directory of block explorers for every supported chain, with address / transaction / block deep links. |
| **Protocol Links** | `#/protocols` | Searchable directory of 110+ DeFi protocols, infrastructure and security tools, grouped by category. |
| **Cache Manager** | `#/cache` | Inspect, edit, export and import the local cache: contract names/symbols/ABIs, signature lookups, settings and custom labels. |

## Supported inputs

The Payload Parser accepts, in addition to raw hex calldata:

- **Block explorer links** — `https://etherscan.io/tx/0x…` and compatible explorers for every
  configured chain.
- **Safe links** — `https://app.safe.global/transactions/…`, resolved through the Safe Transaction
  Service.
- **Tenderly Virtual Environment links** —
  `https://dashboard.tenderly.co/explorer/vnet/{id}/tx/{hash}`. The environment's parent network is
  discovered automatically and the transaction is read over the environment's public JSON-RPC.
- **Tenderly shared simulations** — `https://www.tdly.co/shared/simulation/{id}`.
- **Tenderly explorer transactions** — `https://dashboard.tenderly.co/tx/{network}/{hash}`.

Account-scoped Tenderly simulator URLs (`/{account}/{project}/simulator/{id}`) and bare Virtual
Environment URLs cannot be read without a Tenderly API key; the parser explains this instead of
failing silently.

## Supported chains

`src/utils/chains.js` configures 60+ EVM networks, including Ethereum, Optimism, Arbitrum, Base,
Unichain, Polygon, BNB Chain, Gnosis, Sonic, Monad, Ink, Soneium, Abstract, Berachain, Blast, Linea,
Scroll, Taiko, Mantle, Mode, Zora, Katana, MegaETH, Plasma, HyperEVM, ApeChain, BOB, Hemi, Fraxtal,
Celo, Avalanche, Sei, Rootstock, Flare and several testnets.

Each entry carries a verified block explorer, one or more public RPC endpoints, and optionally an
`apiUrl` for explorers that are not served by the unified Etherscan V2 API (Blockscout, Routescan or
a native Etherscan-compatible API). RPC selection rotates automatically and backs off failing
endpoints.

## Development

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev      # start the Vite dev server
npm run build    # production build to ./dist
npm run preview  # serve the production build locally
```

The app is deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
Vite is configured with `base: '/tools/'`, and the router uses hash history so deep links work
without server-side rewrites. `dist/` is generated by CI and is intentionally not committed.

### Project layout

```
src/
  components/       shared UI (common/ and layout/)
  composables/      Vue composables (chain, clipboard, storage, address display, loading)
  config/           signature database and preset method definitions
  router/           hash-history routes
  styles/           CSS variables, base styles, component styles
  utils/
    core/           ethers access, address helpers, Etherscan API client
    chains.js       chain / explorer / RPC / ABI-API registry
    linkParsers.js  explorer, Safe and Tenderly link parsing
    decoder.js      calldata decoding (Safe, multicall, nested bytes)
    signature.js    4byte lookup + persistent signature cache
    solidityParser.js  Solidity source to function signatures
    multicall.js    Multicall3 encoding/decoding helpers
    abiFetcher.js   verified ABI fetching with proxy resolution
    ...             storage, caching, contract names, API clients
  views/            one component per tool
```

## External services

The tools call public APIs directly from the browser:

- [Etherscan V2](https://api.etherscan.io/v2/api) for verified ABIs and source code, plus
  per-explorer Etherscan-compatible APIs for chains Etherscan V2 does not cover.
- [4byte (Sourcify)](https://api.4byte.sourcify.dev) and the
  [4byte directory](https://www.4byte.directory) for selector lookup and submission.
- [Safe Transaction Service](https://docs.safe.global/core-api/transaction-service-overview) for Safe
  transaction details.
- [Tenderly](https://docs.tenderly.co) public endpoints for Virtual Environment network discovery,
  Virtual Environment JSON-RPC, shared simulations and explorer transaction resolution.
- [chainlist.org](https://chainlist.org)-listed public RPC endpoints for on-chain reads.
- GitHub / GitLab APIs (and their raw file endpoints) for repository-based signature extraction.

Etherscan API keys used by the build are public and rate-limited by design. They can be replaced at
build time with a comma-separated list:

```bash
VITE_ETHERSCAN_API_KEYS="key1,key2,key3" npm run build
```

## Notes

- `ethers.js` v5 is loaded globally from a CDN (see `index.html`) and accessed through
  `src/utils/core/ethers.js`. Any module that needs it should import `getEthers()` / `getEthersSafe()`
  rather than touching `window.ethers`.
- All data fetching happens in the browser, so some public endpoints may be rate-limited or blocked
  by bot protection. Failures are surfaced in the UI rather than swallowed.
- The Vanity Generator creates real private keys in your browser. Treat any generated key as
  compromised if it was produced on an untrusted machine, and never share it.
